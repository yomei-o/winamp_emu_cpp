Winamp 2.95 on waemu — Windows 版の exe をそのままブラウザで

読み込んでいます…
ファイル — Winamp から見える C:\Music の中身。MP3 はここか画面へドラッグ＆ドロップしても入れられます。 ● は入れたもの（このブラウザに残ります）。▶ で再生、＋ でプレイリストに追加
C:\Music

これは何か

Windows 版 Winamp 2.95（2003 年、Nullsoft）の実行ファイルとプラグイン （winamp.exe・in_mp3.dll・out_wave.dll）を、改造せずに x86 エミュレータの中で動かしています。Windows の API（user32・gdi32・winmm など）はエミュレータの側で 作り直したもので、MP3 のデコードも x86 の命令を一つずつ解釈して行っています。 音は waveOut に書かれた PCM を AudioWorklet で鳴らしています。ファイルはブラウザの中だけに置かれ、どこにも送信されません。

操作

最初に画面右上の「音を出す」か、画面をクリック（ブラウザの決まりで、クリックするまで音が出せません）
曲を鳴らす下のパネルの ▶。MP3 はパネルか画面へドラッグ＆ドロップで入れられます。サンプルとして doremi.mp3 があります
キーボード画面をクリックしてから。Winamp のキー操作（X 再生・C 一時停止・V 停止・Z/B 前/次）が使えます
右クリックWinamp のメニュー。右ボタンが無いときは Ctrl＋クリック

権利

Winamp は Nullsoft の著作物です。comctl32.dll は Wine（LGPL）、フォントは IPAex（IPA フォントライセンス）ほか。詳しくは リポジトリの README をご覧ください。
